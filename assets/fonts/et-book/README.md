# ET Book

Police conçue par Dmitry Krasny, Bonnie Scranton et Edward Tufte ; conversion web par Adam Schwartz. Licence MIT, reproduite dans `static/fonts/et-book/LICENSE.txt` et livrée avec le site.

Source : https://github.com/edwardtufte/et-book

Révision : `24d3a3bbfc880095d3df2b9e9d60d05819138e89`.

Fichiers WOFF inchangés, renommés pour leur usage local :

- `roman.woff` : `et-book/et-book-roman-old-style-figures/et-book-roman-old-style-figures.woff`
- `italic.woff` : `et-book/et-book-display-italic-old-style-figures/et-book-display-italic-old-style-figures.woff`
- `bold.woff` : `et-book/et-book-bold-line-figures/et-book-bold-line-figures.woff`

Le site ne télécharge aucune police à l’exécution. L’habillage CSS est propre au manuel, inspiré des principes de Tufte ; aucun thème Hugo tiers n’est installé.
